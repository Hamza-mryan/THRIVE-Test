# حالة تنفيذ THRIVE

آخر مراجعة: 6 نوفمبر 2026. النسخة الحالية MVP تطويرية مترابطة بقاعدة بيانات فعلية، مع حسابات وأدوات وخدمات تجريبية موسومة بوضوح. راجع [تقرير المراجعة والنواقص](REVIEW_2026-11-06.ar.md) و[طريقة التشغيل](RUN_LOCAL.ar.md).

تحديث مقارنة PDF: [جدول المطابقة الكامل](PDF_REQUIREMENTS.ar.md). أضيف الشعور اليومي وملخص النشاط وصفحات الخصوصية والشروط وروابط الدعم وتدقيق الفحص. اختبارات الإضافات اجتازت34 للخادم و24 لـFlutter؛ مع10 للإدارة يصبح المجموع68. تبقى البنود السريرية والمؤسسية غير مكتملة كما يحدد الجدول.

## الوظائف المنفذة

| الجزء | السلوك الحالي |
|---|---|
| الدخول والموافقة | هوية تطوير صريحة، فصل الخدمة عن البحث، تعديل البحث وسحب الخدمة وتسجيل القرارات تاريخيًا |
| Check والنتائج | جولة تجريبية، حفظ إجابات بالخادم، إيقاف واستكمال، احتساب تقني بالخادم، نتيجة ثابتة وسجل جلسات |
| Guide | بحث وتصنيف وتفاصيل ومصدر ونسخة، وتنزيل المحتوى المنشور وقراءته دون اتصال حتى قبل الدخول |
| Connect وPlus | دليل خدمات تجريبية بمستويين، تفاصيل، موافقة مشاركة، طلب إحالة ومتابعة وإلغاء |
| الحساب | مراجعة الموافقة وتعديل البحث وسحب الخدمة، وإغلاق التبويبات الوظيفية عند السحب |
| السلامة | مساعدة من البداية والتبويبات والصفحات الفرعية؛ تعمل دون شبكة ودون أرقام مختلقة أو ادعاء مراقبة مستمرة |
| إدارة الجامعة | دور UniversityAdmin، إضافة وتعديل الخدمات والموارد ونشر المحتوى، ومعالجة حالات الإحالات |
| التقارير | مؤشرات مجمعة مع إخفاء الأعداد الصحية الأقل من5، دون نتائج فردية أو هويات طلاب |
| البيانات والصلاحيات | PostgreSQL وmigrations، نطاق مستخدم وجامعة، تدقيق موافقات وانتقالات إحالة، حماية التزامن ومنع إحالتين مفتوحتين متماثلتين |
| التشغيل | تشغيل منفصل وموحد، إيقاف العمليات المسجلة، بناء Android debug، OpenAPI وCI مع اختبار PostgreSQL |

## التحقق المنجز

- Backend: بناء Release دون تحذيرات أو أخطاء، format ناجح، و34 اختبارًا ناجحًا.
- Flutter: تحليل وتنسيق ناجحان، و24 اختبارًا ناجحًا تشمل الخصوصية والشعور اليومي وروابط الدعم.
- Angular: بناء إنتاجي وتنسيق ناجحان، و10 اختبارات ناجحة. المجموع68 اختبارًا آليًا.
- نجح `scripts/verify-development.mjs` على PostgreSQL فعلية: الجلسات والتحقق من الإجابات والنتيجة المتكررة، نشر المحتوى، صلاحيات الإدارة، الإحالات والسحب وإعادة الموافقة.
- نجح فحص الطالب من الواجهة الفعلية: حفظ وإيقاف واستكمال وإرسال، تنزيل مورد وقراءته بعد إعادة فتح الصفحة دون شبكة، طلب وإلغاء إحالة، تعديل البحث وسحب الخدمة، ومساعدة داخل الصفحات ودون شبكة.
- نجح فحص الإدارة من الواجهة الفعلية: إنشاء وتعديل خدمة ومورد منشور، ظهورهما للطالب، معالجة إحالة حتى Completed وظهور حالتها للطالب، الخروج، RTL/LTR، وشاشة390px دون تمدد أو أخطاء JavaScript.
- نجح بناء Android arm64 debug في `output/android/THRIVE-development-arm64.apk`. لم يختبر على جهاز أو محاكي؛ تحقق التشغيل المرئي تم عبر web. iOS لم يُبنَ لعدم توفر macOS/Xcode.
- ملف CI موجود مع PostgreSQL واختبار الربط؛ لم يشغّل على GitHub ولم يُنشر المشروع.

اختبارات Backend المعزولة تستخدم SQLite relational وJWT فعليًا؛ تحقق PostgreSQL المنفصل يؤكد مخطط القاعدة والرحلات على المزود المستهدف.

## حدود التشغيل الفعلي

- الدخول اصطناعي ومفعّل صراحة في Development. يلزم مزود الجامعة الحقيقي وتهيئة claims والأدوار قبل استخدام الطلاب.
- DEMO-CHECK أسئلة لاختبار استخدام المنتج؛ مجموعها تقني دون معنى نفسي أو ألوان سريرية. HADS وPSS ينتظران النصوص والترخيص واعتماد القواعد.
- الموارد الحالية إرشادات استخدام تجريبية وليست علاجًا أو محتوى سريريًا معتمدًا. الخدمات اصطناعية ولا تتصل بمقدمي رعاية فعليين.
- اعتماد جهات فعلية يحتاج بيانات الجامعة ومعلومات المراجع وإجراء التحقق المؤسسي. نموذج الإدارة الحالي يحفظ خدمات غير موثقة ويمنع تحويل التجريبي إلى جهة فعلية بعلامة اختيار.
- لا ترسل البيئة رسائل خارجية ولا تحجز في نظام آخر. Scheduled تأكيد حالة بواسطة مشغل التجربة، وليس تكامل تقويم.
- سياسة الموافقة مسودة تطوير. تعتمد سياسات الخصوصية والاحتفاظ والحذف والبحث وخطة الاستجابة البشرية قبل جمع بيانات طلاب حقيقية. لا يوجد تصدير بحثي أو حذف حساب نهائي في هذه النسخة.
- التوكن والإجابات والنتائج لا تخزن على الجهاز. المحتوى العام المنشور وحده قابل للتنزيل. جلسة المتصفح في الذاكرة؛ إعادة فتحه تتطلب دخولًا جديدًا.
- APK توقيعه debug وعنوان API الافتراضي لمحاكي Android. يحتاج الجهاز الفعلي إلى عنوان تطوير قابل للوصول؛ النشر يحتاج HTTPS وتوقيع إنتاجي واستضافة ومراجعات الإطلاق.

## التشغيل

من جذر THRIVE على Windows:

```powershell
./scripts/start-project.ps1 -EnableDevelopmentIdentity
```

الطالب `http://localhost:5300`، الجامعة `http://localhost:4200`، وجاهزية الخادم `http://localhost:5180/health/ready`. أول تجميع قد يحتاج دقيقة. السجلات في `.local` وأسرار PostgreSQL خارج Git. أغلق الخوادم القديمة التي تستخدم هذه المنافذ قبل الأمر.

```powershell
./scripts/stop-project.ps1
```

الإيقاف يحافظ على PostgreSQL وبياناته. تفاصيل كل تطبيق وبناء APK في README الخاص به، ومخطط الملفات في FRONTEND_MAP.ar.md. ملفات البناء والسجلات وأدوات SDK المحلية خارج Git.
