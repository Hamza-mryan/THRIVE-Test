## الحالة الحالية

النسخة التطويرية مربوطة فعليًا من الواجهات إلى PostgreSQL. يستطيع الطالب إدارة الموافقة، بدء جولة تجريبية وحفظها واستكمالها ورؤية النتيجة والسجل، قراءة الموارد وتنزيل المنشور منها دون اتصال، وطلب إحالة ومتابعتها وإلغاؤها. تستطيع الإدارة إنشاء وتعديل الخدمات والموارد ونشر المحتوى ومعالجة حالات الإحالات وعرض تقارير مجمعة تحجب الأعداد الصغيرة.

الحسابات والدليل وأداة الأسئلة الحالية تجريبية وموسومة، وتفعيلها صريح في بيئة التطوير. أسئلة DEMO-CHECK تختبر استخدام التطبيق؛ نتيجتها مجموع تقني دون تفسير نفسي. الدخول الجامعي والأدوات السريرية والجهات الفعلية والتكاملات الخارجية تنتظر إعداد الجامعة واعتماداتها. لا تجمع بيانات طلاب حقيقية بهذه الإعدادات. اقرأ [حالة التنفيذ والتحقق](docs/DEVELOPMENT_STATUS.ar.md).

## تشغيل الأجزاء الثلاثة على Windows

من هذا المجلد، بعد توفر التبعيات المذكورة في README لكل تطبيق:

```powershell
./scripts/start-project.ps1 -EnableDevelopmentIdentity
```

تبدأ التطبيقات في عمليات مخفية وينتظر المشغّل جاهزية الخادم والواجهتين قبل إظهار النجاح. أول تجميع يحتاج بعض الوقت؛ السجلات في `.local/thrive-test`. يمكن إبقاء THRIVE الأصلي يعمل على منافذه؛ يتوقف المشغّل دون قتل أي خدمة إذا وجد أحد منافذ الاختبار مشغولًا. سجل العمليات المتقادم من إقلاع سابق يُنظف تلقائيًا بعد التحقق.

```powershell
./scripts/stop-project.ps1
```

أمر الإيقاف ينهي العمليات التي سجلها المشغّل فقط، ويحافظ على قاعدة البيانات وملفاتها. لتشغيل جزء واحد استخدم start-backend أوstart-student أوstart-admin داخل scripts، مع نفس علم التفعيل التجريبي عند الحاجة.

اختبار الربط على بيانات اصطناعية فقط بعد جاهزية الخادم:

```powershell
node scripts/verify-development.mjs
```

عناوين التطوير: الطالب `http://localhost:5400`، الجامعة `http://localhost:4300`، وجاهزية الخادم `http://localhost:5280/health/ready`. [مخطط الواجهات](docs/FRONTEND_MAP.ar.md) يوضح تنظيم الشاشات والمنطق.

جذر مستودع Git هو المجلد الأب الذي يحتوي `THRIVE/`. لا تنشئ مستودع Git متداخلًا هنا. ملف GitHub Actions موجود في `../.github/workflows/thrive-ci.yml` ويستخدم `THRIVE/` كمجلد عمل حسب الجزء. نتائج الفحص المحلي ونتائج GitHub Actions تُتحقق كلٌّ على حدة.
