# مراجعة التصميم واستكمال الفجوات

تحديث 6 نوفمبر 2026 بناءً على طلب مطابقة أوضح للمرجع وتجربة أجمل للموبايل.

## ما تغير

- هوية موحدة: خلفية كريمية، أخضر/teal داكن، وألوان أزرق ونعناعي ومشمشي وبنفسجي للوحدات الأربع؛ تحسين الخطوط والبطاقات والحقول والتنقل وزر المساعدة.
- رسم متجهي أصلي لحديقة جامعية وبوابة وأشجار في الترحيب والرئيسية، دون تحميل صور خارجية أو الادعاء بأنه صورة لجامعة محددة.
- وحدات الرئيسية 2×2 على الهاتف المعتاد، وتتحول إلى عمود للشاشة الضيقة أو تكبير النص. اختصار السجل يعمل، والمساعدة العاجلة ثابتة فوق التبويبات.
- رسم شعور تفاعلي لآخر 7/30 يومًا، مع وصف نصي لقارئ الشاشة واختيار النقاط. لا استيفاء للأيام المفقودة ولا قيم وهمية ولا تصنيف نفسي للشعور.
- مخطط دائري في السجل يصف عدد جلسات الاستخدام المكتملة والمعلقة فقط، وليس نسبًا للتعافي أو التشخيص.
- مكتبة Guide تعرض المواضيع الستة الواردة بالمرجع وتصنيفات مترجمة ورسوم بطاقات، وروابط المصادر وحالة المراجعة والتنزيل الصريح.
- ست مواد تثقيفية أولية عربية/إنجليزية، منشورة ضمن بوابة التطوير فقط وبانتظار مراجعة مختص الجامعة. لا تُقدَّم كمحتوى معتمد أو علاج.
- تمرين تنفس بصري اختياري بخمس دقائق، دون حبس للنفس، يعمل محليًا بعد تنزيل المورد، مع الإيقاف وإعادة الضبط والتوقف عند مغادرة التطبيق أو فتح نافذة أخرى مثل المساعدة العاجلة. ليس أداة استجابة للأزمات.
- دليل الخدمات: هاتف وبريد وتخصص ومصدر، إدارة وValidation وترحيل بيانات وعقد API محدث، مرشحات علم النفس والطب النفسي وملف تفاصيل. الاتصالات لا تعمل للجهات الاصطناعية وغير المتحققة.

## مصادر المواد الأولية

- إدارة التوتر وتنظيم الوقت: [NHS Stress](https://www.nhs.uk/mental-health/feelings-symptoms-behaviours/feelings-and-symptoms/stress/).
- الامتحانات: [NHS Student stress](https://www.nhs.uk/mental-health/children-and-young-adults/help-for-teenagers-young-adults-and-students/student-stress-self-help-tips/).
- النوم: [NHS Sleep](https://www.nhs.uk/every-mind-matters/mental-wellbeing-tips/how-to-fall-asleep-faster-and-sleep-better/).
- التنفس: [NHS Breathing exercises](https://www.nhs.uk/mental-health/self-help/guides-tools-and-activities/breathing-exercises-for-stress/).
- مقدمة التأريض: [WHO Doing What Matters](https://www.who.int/thailand/activities/doing-what-matters-in-times-of-stress). مقدمة قصيرة مع رابط، دون نقل أو ترجمة تمارين الدليل.

لا يحمل أي مورد جديد تاريخ مراجعة مختص وهميًا. المواد ليست نسخة مرخصة أو ترجمة معتمدة من NHS/WHO؛ هي صياغة تثقيفية قصيرة للتطوير مع إسناد واضح للمصدر.

## حدود المطابقة

الأدوات النفسية المرخصة وترجمتها المعتمدة ونتائج المجالات الثلاثة وتدرجاتها واتجاهاتها، ومحرك السلامة والتصعيد البشري، والهوية الجامعية الفعلية، والدليل المؤسسي الموثق والحجز الخارجي والصوتيات ما زالت غير مكتملة. لا نعتبر الشعور اليومي أو DEMO-CHECK بديلًا لهذه المتطلبات. جدول `PDF_REQUIREMENTS.ar.md` يميز المكتمل والجزئي والمتبقي.

## التحقق

- 81 اختبارًا ناجحًا: 40 Backend و10 للوحة الإدارة و31 Flutter، مع تحليل Flutter نظيف وبناء Android x86_64 وWeb ناجحين. اختبارات التنفس تغطي الإيقاف عند فتح المساعدة والخلفية والإتمام وإعادة الضبط؛ اختبارات الرسم تغطي البيانات المفقودة والعربية والنص الكبير والتبديل بين الفترات.
- فحص تكامل PostgreSQL: الملكية والموافقة والحفظ والاستكمال والإرسال والموارد والإحالات وحالاتها وسحب الموافقة؛ بيانات التطوير اصطناعية فقط.
- ترحيل `ServiceContactDetails` مطبق محليًا، وعقد `contracts/openapi/thrive-v1.json` مصدر من الخادم الجديد.
- فحص متصفح حي بالعربية والإنجليزية نجح: الرئيسية والسجل ورسم 30 يومًا والمواضيع الستة والتحكم بالتنفس والتخصصات والمساعدة، دون أخطاء JavaScript. لقطات المراجعة في `.local/redesign-*.png`، وسكربت الفحص `.local/visual-redesign.cjs`؛ كلاهما خارج Git. ظهرت واجهة Guide الجديدة أيضًا على محاكي API 37 بمعمارية x86_64.
- نسخة المحاكي: `output/android/THRIVE-development-x64.apk`؛ رابط API `http://10.0.2.2:5180`. المشروع ليس جاهزًا للإطلاق السريري.
