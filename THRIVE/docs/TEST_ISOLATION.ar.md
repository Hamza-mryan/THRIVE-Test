# تقرير عزل THRIVE Test

تاريخ الفحص: 6 نوفمبر 2026. نطاق العمل: عزل بيئة التطوير في النسخة الموجودة على Desktop فقط، دون تحسين التصميم أو إعادة هيكلة قواعد التطبيق.

## الهوية والتقنيات

المشروع Flutter 3.47.9 / Dart 3.13.7 للطالب، Angular 22 للإدارة، ASP.NET Core / .NET 10 وEF Core للـBackend، وPostgreSQL 17. ليس مشروع Expo أو React Native.

لا توجد روابط استقبال Deep Links أو CFBundleURLTypes أو Associated Domains أو App Groups أو sharedUserId مضبوطة في المشروع. روابط التنقل داخل Flutter داخلية. تغيّرت هوية Web Manifest إلى /thrive-test والاسم والعنوان إلى THRIVE Test. بُني Web وفُحص Manifest الناتج. خادم flutter run التطويري يعيد رسالة manifest not generated in run mode بدل الملف؛ تثبيت PWA نفسه لم يُختبر.

## قاعدة البيانات والخدمات

- أُنشئ cluster PostgreSQL جديد تمامًا داخل .local/thrive-test/postgresql/data، بقاعدة thrive_test وكلمة مرور عشوائية جديدة. المقارنة أثبتت اختلاف كلمة مرور الاختبار عن كلمة مرور الأصل دون عرض أي منهما.
- معرّف نظام cluster الأصلي 7703996488423226804، والتجريبي 7705123887278288332؛ قرئت المعرّفات بأداة pg_controldata دون الاتصال بقاعدة الأصل.
- قبل migrations يتحقق السكربت بقراءة current_database وcurrent_user وinet_server_port وdata_directory الفعلي، إضافة إلى سجل ملكية مرتبط بمسار هذه النسخة ومعرّفها المحلي.
- طبقت EF migrations على thrive_test فقط. لم تُحذف أو تُعد تهيئة قاعدة الأصل، ولم تُنسخ منها بيانات.
- يرفض Backend الاتصال باسم أو مستخدم أو منفذ مختلف، أو بمضيف بعيد. يعرض /health/isolation هوية قاعدة الاتصال الفعلية في Development، دون كلمات مرور أو توكنات.
- الحسابات والجامعات والخدمات المنشأة في الاختبارات اصطناعية. لا توجد رسائل بريد أو SMS أو حجوزات فعلية من هذا المسار.
- لا يوجد Firebase أو Supabase أو مزود هوية خارجي نشط. ترفض نسخة Test إعداد Authority/Audience خارجيين. JWT له issuer/audience خاصان بالاختبار ومفتاح عشوائي في ذاكرة كل تشغيل.
- تتحقق واجهتا Flutter وAngular من هوية THRIVE Test وthrive_test قبل طلب جلسة التطوير. يرفض بناء Android عنوان الأصل أو عنوانًا بعيدًا.

## التخزين وبيئة التشغيل

التوكنات والجلسات في الذاكرة فقط، ولا تُحفظ في cookies أو localStorage أو SharedPreferences. البيانات الوظيفية في قاعدة الاختبار. SharedPreferences يحتوي نصوص الدليل العامة المنزّلة فقط تحت المفتاح الجديد. أصل Web منفصل بالمنفذ، وAndroid له sandbox وUID منفصلان. عزل UserDefaults في iOS يعتمد على Bundle ID الجديد ولم يُفحص على جهاز iOS.

أدوات SDK ومخازن الحزم المثبتة مشتركة كأدوات تطوير؛ لا تُستخدم كقاعدة بيانات أو مخزن جلسات. Gradle ومخرجات البناء وسجلات العمليات وملفات المحاكي القابلة للكتابة تخص هذه النسخة. لا يستخدم المشغّل رابط Flutter العالمي أو مرآة Android الخاصة بالأصل.

أدوات PostgreSQL المحمولة لا تتعامل مع المسار العربي؛ لذلك أُنشئ حرف قرص غير مستخدم، T: حاليًا، يشير إلى جذر الاختبار نفسه. تتحقق الدوال من وجهته عبر Windows Unicode API، ولا تستبدل أي حرف مستخدم. البيانات تبقى فعليًا داخل المشروع.

سجل العمليات الجديد في .local/thrive-test/test-processes.json مرتبط بمسار المشروع ومعرّف نسخته ووقت بدء كل PID. سكربت الإيقاف يرفض سجلات التطبيقات أو النسخ الأخرى. المنافذ المشغولة تسبب توقف المشغّل دون قتل صاحب المنفذ.

## حادثة بيانات البناء المنسوخة والاستعادة

أثناء التحقق ظهرت ثلاثة ملفات ترجمة مولّدة مفقودة في الأصل: app_localizations.dart وapp_localizations_ar.dart وapp_localizations_en.dart. احتوت سجلات Flutter المنسوخة على مسارات مخرجات مطلقة للأصل؛ كود أداة البناء يحذف المخرجات السابقة التي لم تعد ضمن المخرجات الجديدة.

بعد موافقة المستخدم الصريحة أُعيدت الملفات الثلاثة المفقودة فقط من نسخ مطابقة لبصماتها قبل المهمة، مع رفض استبدال أي ملف قائم مختلف. ثم طابقت المقارنة محتوى ملفات المصدر والإعدادات الأصلية الـ281 مع بصمات البداية دون اختلاف.

أُضيف عزل لحالة البناء المولّدة قبل تشغيل Flutter وBackend وAngular؛ تُنقل السجلات غير المملوكة إلى quarantine داخل الاختبار. ويتحقق Flutter قبل كل تشغيل عبر الأدوات الموثقة من أن مسارات مخرجاته ضمن هذه النسخة. أثبت اختباران مستقلان حفظ ملف شاهد يمثل مخرج الأصل، وعزل السجلات المنسوخة ثم رفض إعادة إدخال مسار مخرج خارجي. لم تُنفّذ أوامر تنظيف Flutter على السجلات المنسوخة.

حزمة الاستعادة وبصماتها محفوظة في .local/thrive-test/audit/restore-original-l10n. هذه مقارنة للمصدر والإعدادات المحددة في اللقطة، وليست ادعاءً بوجود لقطة لكل ملف cache مولّد في الأصل.

## الحدود المتبقية

- iOS: تحقق ثابت للهوية والإعدادات؛ لم يُبنَ أو يُثبّت لعدم وجود macOS/Xcode.
- Docker: Compose له اسم project وvolume ومنفذ مستقل، لكنه لم يُشغّل. المسار الموثق والمتحقق يستخدم PostgreSQL المحلي المحمول؛ سكربتاته ترفض data_directory غير المملوك، بما فيه Docker غير المتحقق.
- بناء Web نجح مع تحذير من الأداة عن خط CupertinoIcons غير الموجود؛ لم يُعدّل التصميم أو إعداد الخطوط ضمن هذه المهمة.
- لم تُنفّذ اختبارات هاتف فعلي أو ARM64 أو تثبيت PWA. نسخة APK المختبرة x86_64 وdebug، وليست حزمة نشر.
- مصادقة الجامعة الحقيقية وإعدادات الإنتاج ليست ضمن هذا الاختبار وتبقى غير مفعّلة.
- الوثائق المؤرخة السابقة تصف تاريخ المشروع قبل العزل؛ تعليمات التشغيل الحالية هي هذا التقرير وRUN_LOCAL.ar.md وREADMEs المحدّثة.

~~~powershell

~~~

الطالب http://localhost:5400، الإدارة http://localhost:4300، والخادم http://localhost:5280. إذا كان الاختبار يعمل بالفعل، لا تشغّل نسخة أخرى من المشغّل.

~~~powershell
node scripts/verify-isolation.mjs
.\scripts\verify-generated-isolation.ps1

~~~

.\scripts\stop-database.ps1
~~~
