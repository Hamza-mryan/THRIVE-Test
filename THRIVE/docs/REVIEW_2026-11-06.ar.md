المجموع61 اختبارًا آليًا بعد الإصلاح. اختبار الربط والمتصفح تحققان إضافيان، وليسا مضافين لهذا العدد. فحص الحزم ليس تدقيق اختراق أو ضمانًا أمنيًا عامًا. لم تنفذ المراجعة اختبار حمل أو استعادة نسخة احتياطية أو مراجعة قانونية أو سريرية.

## الإصلاحات

1. مكوّن Flutter المشترك AsyncContent كان يعيد Future من callback الخاص بـsetState عند تحديث البيانات. ظهر الخطأ في وضع debug بعد عمليات ناجحة، وكان يؤثر على إعادة تحميل السجل والموارد والإحالات. أصبحت العملية تبدأ الطلب خارج callback وتحدث الحالة بشكل متزامن، مع تجاهل طلب إعادة التحميل بعد التخلص من المكوّن. أضيف اختبار للتحديث واختبار للاستدعاء المتأخر.
2. مشغّل المشروع كان يعلن بدء العمليات قبل التأكد من جاهزية التطبيقات. صار ينتظر health/ready وواجهتي الطالب والإدارة، ويتوقف برسالة واضحة عند فشل جزء أو انتهاء مهلة الإقلاع وينظف العمليات التي أنشأها.
3. سجل العمليات بعد إعادة إقلاع Windows كان يمنع إعادة التشغيل حتى إزالته يدويًا. المشغّل الآن يتحقق من رقم العملية ووقت بدايتها، ثم يزيل السجل المتقادم فقط دون إيقاف عملية أخرى أُعيد استخدام رقمها.

| أساسي | الأداة الوحيدة DEMO-CHECK، ونتيجتها مجموع تقني دون تفسير نفسي | أدوات مرخصة ونصوص معتمدة وقواعد بإصدارات ومراجعات سريرية واختبارها قبل تفعيلها |
| أساسي | السلامة صفحة محلية عامة؛ لا أداة سلامة معتمدة أو محرك تصعيد فعلي أو أرقام موثقة | بروتوكول معتمد وبيانات اتصال حقيقية ومسار مراجعة بشرية وصلاحيات مختصين واختبارات مستقلة |
| أساسي | دليل الجامعة والمتخصصين اصطناعي؛ التحقق المؤسسي غير منفذ كمسار مراجعة | بيانات الجامعة وآلية مراجعة ومؤهلات وتواريخ اعتماد وصلاحيات، مع تفعيل الجهات الموثقة فقط |
| أساسي | الموارد الحالية إرشادات استخدام للمنتج وليست مكتبة دعم نفسي مراجعة | محتوى ومصادر وحقوق ومراجعات وتواريخ تحديث؛ آلية سحب وتحديث النسخ المنزلة عند الحاجة |
| أساسي | الموافقة مسودة؛ لا سياسة تشغيلية للاحتفاظ والحذف أو حذف حساب نهائي | اعتماد النصوص وتنفيذ دورة حياة البيانات حسب القرار المؤسسي، وتوثيق التصدير البحثي إن كان مطلوبًا |
| قبل النشر | لا استضافة إنتاجية أو TLS أو توقيع إنتاجي أو اختبار استعادة/حمل/اختراق موثق | إعداد الاستضافة والأسرار والتخزين والمراقبة والنسخ الاحتياطي والتحقق من الاستعادة والأداء والأمن |
| قبل النشر | Android بُني ولم يُجرّب على جهاز؛ iOS لم يُبنَ | اختبارات أجهزة ومحاكي وmacOS/Xcode والتوقيع والتوزيع ومراجعة الوصول |
| حسب نطاق الجامعة | لا إرسال خارجي أو تكامل حجز أو تنبيهات فعلية | تحديد التكامل المطلوب وتأكيد التسليم ومواعيد الاستجابة البشرية؛ حالة Scheduled الحالية محلية |
| نطاق لاحق | لا تسجيل شعور يومي أو رسوم اتجاهات نفسية أو تصدير بحثي | تثبيت الأولوية؛ عدم اختراع اتجاهات أو تفسيرات قبل توفر أدوات وبيانات معتمدة |

كذلك تبقى تحسينات قبل الإنتاج مثل قيود المعدل وأحجام القوائم وإدارة مراجعات المحتوى وتفاصيل تدقيق تغييرات الإدارة بحاجة تقييم وتنفيذ بحسب الاستضافة والحجم المتوقع. النسخة الحالية ليست أساسًا لإرسال بيانات طلاب حقيقية.
